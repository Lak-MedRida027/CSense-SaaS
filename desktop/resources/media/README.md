# Bundled lesson media (placeholder pack)

This folder is the media pack for development, demos and the end-to-end journey test (ADR 0019).
Production video and captions are a content deliverable and arrive with Phase 10 (remote mode).

| File | What it is |
|---|---|
| `placeholder-lesson.webm` | 8 second, silent, 480x270 VP8 title card ("Lesson video placeholder"), about 100 KB. Original work generated by `desktop/scripts/make-placeholder-clip.cjs`; no third-party material, no licence obligations. |
| `m1.vtt`, `m3.vtt`, `m5.vtt`, `m7.vtt` | WebVTT captions. The cue text is the seed transcript for modules 1, 3, 5 and 7, re-timed to the 8 second clip. |
| `manifest.json` | Allowlist. Maps the content URL suffix (after `MAIN_VITE_MEDIA_BASE_URL`) to a file in this folder and its MIME type. Only files named here are ever served, under `app://csense/media/<file>`. |

## Regenerating the clip

There is no ffmpeg dependency. The script renders a canvas title card, encodes it with WebCodecs
(VP8) inside a hidden Electron window and writes the WebM with a small EBML muxer, so the file has
a real Duration and Cues (it seeks). Run from the repository root, then commit the output:

```
npx electron desktop/scripts/make-placeholder-clip.cjs
```

`*.webm` is marked binary in `.gitattributes`. Keep the clip under about 200 KB.

## Adding or replacing media

1. Put the file here (name `^[a-z0-9-]+\.(webm|mp4|vtt)$`) and add an entry to `manifest.json`.
2. The content URL stored on the module must be `<MAIN_VITE_MEDIA_BASE_URL><key>`, for example
   `https://media.example.com/csense/placeholder/m1.mp4`. Anything else shows "Video unavailable"
   and the lesson falls back to its transcript.
3. A video module needs `captionsUrl` and at least one transcript cue (WCAG 1.2.2, 1.2.3).
